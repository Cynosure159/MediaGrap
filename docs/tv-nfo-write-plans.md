# 电视剧 Kodi NFO 安全写入

Phase 3B 支持从已选择的电视剧元数据创建 Kodi NFO 写入计划。

## 计划范围

对一部已匹配的剧创建计划时，系统分别生成：

- 剧目录中的 `tvshow.nfo`；
- 每个已发现季目录中的 `season.nfo`；
- 每个已发现媒体文件旁的同名 `.nfo`，根元素为 `episodedetails`。

多集文件以首个识别到的集号生成一个同名 NFO。多集内容拆分和缺集报告仍属于后续 3B 工作。

## 安全流程

1. 先在 WebUI 中预览每一项的目标路径、XML 和创建/覆盖状态。
2. 每次确认只写入当前这一项；后续计划必须再次确认。
3. 写入采用同目录临时文件、`fsync`、关闭文件、原子重命名的顺序。
4. 每次执行前重新检查路径仍在允许的媒体根目录内，且已有目标必须是普通文件；符号链接和非普通文件会被拒绝。
5. 所有预览和应用都记录到审计表。

此功能不会删除媒体文件。它会替换已有的普通 NFO 文件，因此应先检查 XML 预览；目前不会保留旧 NFO 内容中的未知扩展字段。
