# 电影扩展元数据

选择 TMDb 电影候选后，MediaGrap 以一次详情请求取得基础详情、演职员和分级信息，直接替换本地元数据并立即以原子方式写入 Kodi NFO；这个流程没有“草稿后再保存”的步骤。

## 当前字段

- TMDb 评分与票数；
- 分级：优先使用设置的 TMDb 语言对应国家/地区；没有时回退美国分级；
- 制作公司、导演、编剧（Writer、Screenplay、Story）；
- 前 20 位演员、角色和 TMDb 头像 URL；
- 已有的标题、原名、年份、剧情、片长、类型、海报与背景图。

这些字段显示在电影概览和“演职人员”页。概览中的导演、编剧、制作公司可以单独手动编辑；演员列表来自本次 TMDb 匹配结果。

## Kodi NFO

候选匹配会立即将评分、票数、分级、导演、编剧、制作公司以及每位演员的姓名、角色和头像地址，连同已有电影字段写入 NFO。写入使用同目录临时文件和原子替换；软链接与非普通目标仍会被拒绝。

已有 NFO 的读取也会解析这些字段；扫描时仅在 SQLite 尚无元数据的电影中将解析结果写入 SQLite，因此列表与详情使用同一份数据。目录级本地图片（例如 `poster.jpg`、`fanart.jpg`）的相对路径也会保存到 SQLite sidecar 索引，列表优先通过受鉴权的本地图片接口显示海报。不存在的字段以空值或空数组返回，不以演示数据替代。

## 限制

- 演员头像当前是 TMDb 图片 URL，尚未下载到媒体目录；头像下载属于后续艺术图/人员工坊。
- 不会自动重新刮削或覆写本地元数据。用户必须在候选中明确选择电影。
- 日志记录选择、详情映射和保存结果的字段计数，不记录 API Key、代理地址或完整外部请求 URL。
