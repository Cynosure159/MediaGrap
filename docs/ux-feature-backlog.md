# UX 原型功能盘点

来源：docs/stitch-prototypes 中的 10 个本地 HTML 原型，以及 [UI/UX 设计约束](ui-ux-design.md)。本文将原型中的视觉信息与真实产品能力分开，作为 [项目路线图](roadmap.md) 的功能清单。

状态标记：

- **已具备**：已有可用实现，但未必已完全使用新视觉。
- **部分具备**：已有底层或简化界面，仍缺原型所示行为。
- **待实现**：原型中的功能占位，不能显示为已完成。
- **以后评估**：超出当前产品范围或需要单独安全设计。

## 原型数据使用规则

原型中的片名、图片、评分、尺寸、路径、连接状态、延迟、任务百分比和“无冲突”等内容均为演示数据。实现时必须从 API 获取，加载失败必须显示真实失败状态；不得以静态成功文本替代尚未执行的网络、文件或校验操作。
